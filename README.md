# LogiNews — Headless CMS-Powered Blog / News Platform

A responsive, clean and professional news platform for a fictional **National Logistics Company**, built with **HTML + Tailwind CSS (CDN) + vanilla JavaScript**. The CMS is simulated with mock data, but the code is structured so a real headless CMS (Contentful, Strapi, Sanity, Hygraph) can be plugged in by flipping one config flag.

## 🚀 Features

- **6 pages**: Home, Article, Category, About, Contact, 404
- **Responsive** from 320px → 1440px+, mobile-first
- **Headless CMS ready**: mock data layer with a real API path
- **Reusable UI components** rendered by JavaScript
- **Accessible**: skip links, ARIA labels, focus states
- **Clean design**: Inter + Merriweather, brand navy + blue accent
- **Zero build step**: just open `index.html`
